# J.A.R.V.I.S. для Android

Голосовой ассистент в стиле Jarvis из «Железного человека». Работает в Termux: слушает голос, отвечает вслух и управляет телефоном.

## Возможности
- Открывает приложения: «открой YouTube»
- Фонарик, громкость, яркость, Wi-Fi
- Звонки и SMS контактам
- Будильник и таймер
- Заряд батареи, поиск в Google
- С ключом API: свободный разговор и понимание обычной речи

## Установка
1. Установите **Termux** и **Termux:API** из F-Droid (не из Google Play).
2. Выдайте Termux:API разрешения: микрофон, контакты, телефон, SMS.
3. В Termux выполните:

```bash
pkg install git -y
git clone https://github.com/BlogBoost/Jarvis.ai
cd Jarvis.ai
bash install.sh
python jarvis.py
```

## Режим с ИИ
Создайте ключ на console.anthropic.com и сохраните его:

```bash
echo "ваш_ключ" > ~/.jarvis_key
```

Без ключа работают только простые команды.

## Обновление
```bash
cd Jarvis.ai && git pull
```

## Выход
Скажите «отбой».

## Ограничения
- Нет слова-пробуждения, при каждом прослушивании появляется окно распознавания Google.
- Нажимать кнопки внутри других приложений нельзя.
- Голос системный (синтезатор телефона).
